Featured Work

SKY130 PDK · Verilog
3-Stage Pipelined RISC-V CPU & Cache

Fundamentals

  • 3-stage pipelined RISC-V core (Fetch → Decode/Execute → Writeback)
  • RV32I base integer ISA with full data forwarding
  • GShare branch predictor with 2-bit PHT and tag-indexed BTB
  • 2-way set-associative write-back cache with LFSR replacement

Design Challenges

  • Resolved critical path through ALU by splitting into parallel functional units (adder, comparator, shifter) rather than a monolithic execute stage
  • Implemented a 5-entry FIFO between Fetch and Decode to decouple instruction fetch latency from decode stalls
  • Achieved 1.05 CPI by utilizing multiple ALU units in parallel instead of a single execution path
  • Optimized cache hit path by overlapping tag comparison with data read
