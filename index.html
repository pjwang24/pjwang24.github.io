§ 02 / Featured

Accelera — a RISC-V SoC that thinks.

Personal passion project · Sky130 · OpenLane

A custom RV32IM core with a decoupled INT8 matmul accelerator, a bare-metal MNIST runtime, and an RL-driven autotuner searching the design space — all in one repo, verified cycle-accurate, pushed to GDS, and still evolving on nights and weekends.

Three things set it apart: the accelerator is decoupled (MMIO + command FIFO + 128-bit DMA, not a coprocessor glued to the pipeline), the software stack ships as bare-metal C with no libc, and the compiler passes are autotuned by PPO against a cycle-accurate model. The whole thing runs 100 MNIST images at 100/100 accuracy, 24.45× over a baseline pure-SW inference.

§ 02.1 / Progress

How we got 24.45×.

Stage What changed Speedup
Baseline Pure software inference, -O0, no accelerator. The honest floor. 1.00×
Compiler + fused ops -O3, fused activation+bias, reciprocal instead of division. Free wins. 1.09×
Accelerator v1 4×4 systolic engine via shared dcache port. Functional, but the narrow path bottlenecks bandwidth. 7.30×
128-bit DMA + batch-4 Decoupled 128-bit DMA feed, batched inference to amortize weight loads. 16.77×
4-stage pipeline refactor Rebalanced IF/ID/EX/WB, added forwarding, killed a load-use stall. 16.26×
MMIO/driver fixes Phase-2 driver rewrite, strided-input descriptor, command-FIFO pipelining. 24.45×
